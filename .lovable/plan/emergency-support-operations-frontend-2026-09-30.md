# Emergency Support Operations Frontend

## Build
- Replace the blank home screen with a responsive professional operations console based on the selected Confident Operational direction.
- Add six role modes with role-specific navigation, labels, and filtered information while keeping identities masked.
- Build interactive intake, distress scoring, routing, voice-support, case queue, health, and audit views using realistic mock data.
- Add working search, filters, dialogs, notifications, language selection, mobile navigation, save/register feedback, and a prominent quick-exit action.

## Visual system
- Use a calm dark slate interface with restrained indigo, amber, red, and green status colors.
- Use Space Grotesk for interface text and JetBrains Mono for IDs and operational metadata.
- Keep typography compact, spacing clear, corners restrained, and animation subtle with reduced-motion support.

## Technical details
- Keep this frontend-only; external APIs are represented by safe mock states because the referenced localhost services are not connected.
- Use semantic design tokens and accessible controls with keyboard focus states.
- Add page-specific metadata and verify desktop and mobile layouts in the running preview.
